## 📌 Project Overview

**Bank Customer Data Analysis** is an Exploratory Data Analysis project developed using **Python, Pandas, NumPy, and Matplotlib**.

The project analyzes customer demographics, account types, account balances, occupations, branches, cities, and customer financial patterns to extract meaningful insights from banking data.

---

## 🎯 Objectives

* Analyze customer demographics
* Understand account balance distribution
* Compare savings and current accounts
* Analyze balance by gender
* Analyze balance by occupation
* Compare banking branches
* Analyze customer distribution by city
* Study age vs account balance
* Identify customers with the highest balances
* Create meaningful visualizations
